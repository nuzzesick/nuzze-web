# Changelog

## Version 2.0.0 - Single Page Portfolio (Nov 2025)

### Major Changes
- 🎨 **Complete redesign** - Converted to a clean, minimal single-page portfolio
- 🔤 **Geist Fonts** - Now using Geist Sans and Geist Mono for modern typography
- 📄 **Simplified** - Removed multi-page structure in favor of single-page design with sections
- ♿ **Accessibility Focus** - Clean, readable design with proper semantic HTML

### Features Added
- Smooth scroll navigation
- Sticky header with navigation links
- Experience timeline with all positions
- Dedicated Dogma project section with links
- Contact section with email CTA
- Footer with social links

### Technical Updates
- Next.js 15 with App Router
- TypeScript throughout
- Tailwind CSS 3
- Geist fonts via npm package
- Optimized build size

### Removed
- Old multi-page structure (about, skills pages)
- Complex SVG animations
- Unused components and utilities
- PropTypes (replaced with TypeScript)

### Content Updates
- Based on latest CV
- Current role at Connect Earth
- Dogma co-founder information
- Complete employment history
- Social media links updated
